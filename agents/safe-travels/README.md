# Safe Travels (Agent)

A Microsoft **Copilot Studio** agent template that provides employees with travel assistance — documentation requirements, health and safety guidance, and emergency information — through a natural-language conversational interface.

> **Note:** This is a **Copilot Studio managed template**, installed and configured in Copilot Studio (no instructions block to paste). The default knowledge source covers **US travel destinations** and can be replaced with your own.

## Source

- **Publisher:** Microsoft
- **Official docs:** [Safe Travels template — Microsoft Copilot Studio](https://learn.microsoft.com/en-us/microsoft-copilot-studio/template-safe-travels)

## Why it fits Tribal Nations

Useful for **member/employee travel programs**, per-diem and documentation questions, tribal transit or emergency-travel support, and staff traveling for federal/BIA/IHS business.

## What it does

- Explains travel documentation (passports, visas) needed before departure.
- Surfaces health and safety guidance — vaccinations, local health risks, consulate contacts.
- Provides emergency-assistance details for a destination, including local services and the nearest US consulate.

## Prerequisites

- A **Copilot Studio** license.
- An organization **knowledge base of travel advisory information** (the template ships with `https://travel.state.gov/` as a default you can replace).

## How to deploy

1. In [Copilot Studio](https://copilotstudio.microsoft.com), under **Start with an agent template**, select **Safe Travels**.
2. Open the agent and select **Knowledge** at the top of the page.
3. Add or replace knowledge sources with your organization's travel/advisory content.
4. **Create**, then **Test** and validate responses.

## Extension opportunities

Integrate travel-booking and reservation systems, add local emergency-services and cultural-norms content, language-assistance resources, and streamline travel-request approvals through the agent.

## Limitations

Managed agents and templates are currently **English only** and intended for **internal use**. The default site covers US destinations only. AI-generated content can contain mistakes — review for accuracy. See the [Supplemental Terms](https://go.microsoft.com/fwlink/?linkid=2189520).
