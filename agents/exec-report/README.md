# Exec Report

**Type:** SharePoint skill (Microsoft 365 Copilot / SharePoint)

Generates a polished, self-contained HTML executive report or dashboard from any data source — a SharePoint list, a CSV export, or just a verbal description. It interviews you, builds a validated data structure, then renders a single sandbox-safe HTML file with no external dependencies.

## What you get

- A complete, self-contained HTML executive report with a chosen narrative structure: **Achievement**, **Problem**, or **Status**
- A component library: KPI cards, trend charts, bar breakdowns, comparison panels, status grids, data tables, and narrative highlights
- Four visual palettes: warm paper (cream/terra-cotta), deep ink (dark/gold), clean white (white/green), and slate (gray/blue)
- A **sandbox-safe** file with all JavaScript inline — no CDN links, no external dependencies, works inside a SharePoint iframe

## When to use it

Ask Copilot things like:

- *"build an exec report"* / *"create a one-pager"* / *"make a status dashboard"*
- *"business review for Q2"* / *"project summary page"* / *"generate a visual report"*
- *"here's my SharePoint list data, build a report"* / *"summarize this CSV into a report"*
