# Website Q&A (Agent)

A Microsoft **Copilot Studio** agent template that answers common customer questions using the content on your website. It searches your site and uses generative AI to formulate contextual answers, delivering instant, relevant information and reducing the need for human intervention.

> **Note:** Like [IT Helpdesk](../it-helpdesk), this is a **Copilot Studio managed template** — you install it from Copilot Studio and point it at your website. There is no instructions block to paste. This folder documents how to deploy it.

## Source

- **Publisher:** Microsoft
- **Official docs:** [Website Q&A template — Microsoft Copilot Studio](https://learn.microsoft.com/en-us/microsoft-copilot-studio/template-website-q-and-a)

## What it does

- Searches across your website's content and uses generative AI to answer customer questions in context.
- Provides instant, relevant responses to enhance user experience and reduce manual support load.

## Use cases

- **Customer support** — Address frequently asked questions and provide instant support to website visitors.
- **Product information** — Offer detailed information about products or services to aid decision-making.
- **Educational websites** — Answer questions about courses or educational content.
- **Event management** — Provide details about upcoming events, registration, and related inquiries.

## Prerequisites

- A **Copilot Studio** license for your makers.
- Copilot Studio **message capacity**.
- A **public website** whose content will serve as the knowledge source.

## How to deploy

1. Sign in to **[Copilot Studio](https://copilotstudio.microsoft.com)**.
2. On the **Agents** page, under **Start with an agent template**, select **Website Q&A**.
3. Replace the default knowledge source with a link to your organization's **website**.
4. Select **Create** at the top of the page.
5. **Test** the agent and validate its responses to ensure it answers user queries accurately.

## Limitations

Managed agents and agent templates are currently **English only** and intended for **internal use** within your organization. AI-generated content can contain mistakes — review responses for accuracy. See the [Supplemental Terms](https://go.microsoft.com/fwlink/?linkid=2189520).
