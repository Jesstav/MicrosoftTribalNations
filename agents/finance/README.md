# Finance Agent

A Microsoft 365 Copilot agent that acts as a **Senior Product Manager and Solution Architect for consumer fintech applications**. It helps design, analyze, and explain a mobile-first personal finance app that tracks expenses, categorizes spending, and surfaces actionable savings insights.

> **Heads-up on scope:** This community sample is oriented toward **designing a personal-finance product**, not answering organizational budget/grant questions. It's included as a starting point — to use it for tribal **grant/budget/federal-funding** scenarios, you'd repurpose the instructions accordingly. See [`instructions.txt`](./instructions.txt).

## What it does (as shipped)

- Behaves as a senior PM / solution architect for a consumer fintech app.
- Designs and explains expense tracking, spend categorization, and savings-insight features.
- Responds in a professional, clear, structured manner.

## How to build this agent

This is a **Microsoft 365 Copilot declarative agent** — built in **Copilot Agent Builder**.

1. Open **[copilot.microsoft.com](https://copilot.microsoft.com)** with a **Microsoft 365 Copilot**–licensed account.
2. Go to **Agents → Create agent → Configure**.
3. **Name:** `Finance Agent`
4. **Description:** paste the contents of [`description.txt`](./description.txt).
5. **Instructions:** paste the contents of [`instructions.txt`](./instructions.txt) — edit these to match your finance scenario.
6. Create and test.
