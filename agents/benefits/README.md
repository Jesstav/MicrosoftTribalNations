# Benefits (Agent)

A Microsoft **Copilot Studio** agent template that helps employees understand their company-provided benefits. It sifts through benefits resources and delivers precise, tailored answers in seconds — no time-consuming searching or reading required.

> **Note:** This is a **Copilot Studio managed template**, installed and configured in Copilot Studio (no instructions block to paste). It is designed to run in **Microsoft Teams** and integrates with **SAP SuccessFactors**.

## Source

- **Publisher:** Microsoft
- **Official docs:** [Benefits template — Microsoft Copilot Studio](https://learn.microsoft.com/en-us/microsoft-copilot-studio/template-m365-ext-benefits)

## Why it fits Tribal Nations

Adaptable for **tribal member benefits**, employee benefits for tribal enterprises and government, per-capita/social-services questions, and health/education benefit lookups. Microsoft notes the template can also be adapted for **safety FAQs and other scenarios** needing personalized answers from multiple sources.

## Capabilities

- Answer questions about benefit types for employees and dependents — health, well-being, childcare, education.
- Compare multiple benefit options in a table using the parameters most relevant to the employee.
- Answer clarifying questions interactively and provide links to full benefit details.

## Use cases

- A new hire asks the agent to explain options and help with a complex enrollment decision.
- An employee checks whether a specific benefit is offered to address a challenge they're facing.

## Prerequisites

- **Microsoft Teams** account (preferred platform).
- **Microsoft 365 Business or Enterprise** plan with Teams.
- **SAP SuccessFactors** (benefits data source).

## How to deploy

1. In [Copilot Studio](https://copilotstudio.microsoft.com), under **Start with an agent template**, select **Benefits**.
2. Configure the knowledge sources / SuccessFactors connection with your benefits data.
3. **Create**, **Test**, and validate responses, then **Publish** to Teams.

## Limitations

Managed agents and templates are currently **English only** and intended for **internal use**. AI-generated content can contain mistakes — review for accuracy. See the [Supplemental Terms](https://go.microsoft.com/fwlink/?linkid=2189520).
