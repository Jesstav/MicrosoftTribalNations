# Promptly — Prompt Assistance (Agent)

A Microsoft 365 Copilot agent that helps you craft effective, engaging AI prompts. Promptly analyzes your prompt, offers concise feedback, and guides you step by step to refine it — always warm, encouraging, and focused on building your confidence.

## Use cases

- **Education** — Learn what makes a prompt effective through side-by-side comparisons and step-by-step refinement.
- **Prompt refinement** — Get one or two specific, actionable improvements on any prompt you're working on.
- **Experimentation** — Open-ended coaching questions push you to explore tone, context, and constraints.

## How to build this agent

This is a **Microsoft 365 Copilot declarative agent** — built in **Copilot Agent Builder**.

1. Open **[copilot.microsoft.com](https://copilot.microsoft.com)** (or Copilot in Teams) with an account that has a **Microsoft 365 Copilot license**.
2. Go to **Agents → Create agent → Configure**.
3. **Name:** `Promptly`
4. **Description:** paste the contents of [`description.txt`](./description.txt).
5. **Instructions:** paste the contents of [`instructions.txt`](./instructions.txt).
6. Create the agent and test it by sharing a sample prompt.
