# Customer Comments (Agent)

A Microsoft 365 Copilot agent that manages customer comments and complaints about your services. It analyzes submissions and drafts professional, empathetic, consistent responses based on your complaint-handling guidelines — maintaining a neutral tone that avoids prematurely assigning blame.

## Why it fits Tribal Nations

Well suited to **member/constituent feedback** for tribal services, gaming and hospitality guest comments (e.g., resort/casino operations), and consistent, empathetic responses to public inquiries.

## What it does

- Reviews customer feedback and form submissions from drafts.
- Drafts acknowledgement emails and resolution responses grounded in a "Guidelines for Handling Complaints" document.
- Keeps a professional, neutral tone; focuses on clarity, readability, and effective formatting.

## How to build this agent

This is a **Microsoft 365 Copilot declarative agent** — built in **Copilot Agent Builder**.

1. Open **[copilot.microsoft.com](https://copilot.microsoft.com)** with a **Microsoft 365 Copilot**–licensed account.
2. Go to **Agents → Create agent → Configure**.
3. **Name:** `Customer Comments`
4. **Description:** paste the contents of [`description.txt`](./description.txt).
5. **Instructions:** paste the contents of [`instructions.txt`](./instructions.txt).
6. Add your own complaint-handling guidelines as knowledge, then create and test.
